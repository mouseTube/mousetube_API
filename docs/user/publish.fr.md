# Publier avec un DOI

**Publier** dépose les fichiers d'une session partagée dans un dépôt (Zenodo) et leur donne un **DOI** : un
identifiant permanent que vous pouvez citer et que chacun peut résoudre vers vos données.

## Avant de commencer

- La session est **Shared** (publique). Une session en attente de validation ne peut pas encore être publiée.
- Elle n'utilise aucune fiche qu'un administrateur n'a pas encore validée. La carte Visibility le dit.
- Elle a au moins un fichier prêt.
- Un **protocole** est choisi.

## Publier

À l'étape **File**, ou dans *My vocalizations*, choisissez **Publish in a repository**. Une fenêtre montre un
**aperçu de la description** qui apparaîtra sur Zenodo : titre, description, mots-clés, personnes et licence.
Relisez-le, modifiez ce que vous voulez, et confirmez.

mouseTube envoie ensuite les fichiers en arrière-plan. Vous êtes prévenu quand c'est terminé, et la session
devient <span class="pill red">Published</span> avec son DOI.

!!! info "Vous n'avez pas besoin d'un compte Zenodo"
    mouseTube fait le dépôt pour vous, dans son propre espace sur Zenodo, avec la description que vous avez
    relue, y compris les personnes nommées sur la notice (vous pouvez les modifier dans l'aperçu).

## Publier une fois validé

Si votre session doit attendre un administrateur, vous pouvez demander qu'elle soit **publiée automatiquement**
une fois validée.

1. Dans la carte *Visibility* d'un brouillon, cochez **Publish automatically once validated**, puis partagez la
   session.
2. Comme elle doit attendre, un **aperçu de la publication** s'ouvre. Relisez-le, modifiez-le si vous voulez,
   cochez *I checked the preview and want it published automatically once validated* et choisissez
   **Approve and publish after validation**.
3. Quand un administrateur valide la session, elle est publiée **comme vous l'avez approuvée**, et vous recevez un
   e-mail avec le DOI.

Si ce qui serait publié a changé entre-temps (un administrateur a corrigé une fiche), rien ne part : vous êtes
prévenu, et vous publiez vous-même avec un nouvel aperçu. Vous pouvez **Cancel automatic publication** à tout
moment pendant l'attente.

## Une session publiée continue de vivre

Vous pouvez toujours **modifier** une session publiée : la description et les mots-clés de sa notice suivent, avec
le même DOI. Les **fichiers que vous ajoutez ensuite** font une **nouvelle version** de la notice, avec son propre
DOI ; l'ensemble garde un DOI global qui pointe toujours vers la dernière version. Un fichier d'une version publiée
ne peut pas être retiré.

## Citer vos données

Citez le **DOI** de la version que vous avez utilisée, ou le DOI global pour l'ensemble. Le DOI est affiché sur la
carte de chaque fichier dans **Vocalizations**.
